# Задача: Переименовать Backend в SkladX01

## 1. КОНТЕКСТ
- **Текущая структура:** `SkladNew/backend/` (внутри `SkladApi.sln`, `SkladApi`, `SkladDB`, `HRDB`, `EmailService`).
- **Цель:** Переименовать папку и решение в `SkladX01`, чтобы сохранить историю и обновить все ссылки.

## 2. ЧТО НУЖНО СДЕЛАТЬ

### Шаг 1. Переименовать папку и файл решения
1. Переименуй папку `backend` в `SkladX01`.
2. Внутри `SkladX01` переименуй `SkladApi.sln` в `SkladX01.sln`.

### Шаг 2. Обновить внутренние ссылки
1. Открой `SkladX01.sln` (это текстовый файл) и убедись, что пути к проектам (`.csproj`) остались корректными относительно новой папки.
2. Если в `Program.cs` или других файлах есть жестко прописанные пути к `backend`, обнови их на `SkladX01`.

### Шаг 3. Проверить сборку
Выполни:
```bash
cd SkladNew/SkladX01
dotnet build
```

Если сборка проходит успешно — задача выполнена.

## 3. ОГРАНИЧЕНИЯ
- ✅ Сохранить всю историю Git (если папка была под контролем версий).
- ❌ Не менять названия самих проектов внутри решения (`SkladApi`, `SkladDB` и т.д.), если это не требуется.
