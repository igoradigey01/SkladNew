ИНСТРУКЦИЯ ПО РАБОТЕ С ЛОКАЛЬНЫМ ИИ-АГЕНТОМ (FLINT 40B)
Конфигурация сервера: Intel Xeon E5-2680 v4 (14 ядер) | 64 ГБ RAM | MSI GTX 1080 Ti (11 ГБ VRAM) 

Эта справка содержит всё необходимое для запуска и повседневной работы с вашей оптимизированной моделью flint-local после перезагрузки или остановки сервера. 

1. ПРОВЕРКА И ЗАПУСК СЛУЖБЫ OLLAMA

Обычно служба Ollama в Linux стартует автоматически. Если после перезапуска сервера агент не видит модель, проверьте статус службы. 

Команда для проверки статуса:
sudo systemctl status ollama 

Если статус "inactive" (остановлена) или "failed", запустите службу вручную:
sudo systemctl start ollama 

(Если вы используете ручной запуск Ollama в терминале без системной службы, используйте команду: ollama serve) 

1. ЗАПУСК МОДЕЛИ С АППАРАТНЫМ УСКОРЕНИЕМ (GPU)

Чтобы запустить модель flint-local с правильным распределением нагрузки (20 слоев на видеокарту, 14 физических ядер процессора, 16k контекста) и зафиксировать её в памяти, выполните следующую команду: 

OLLAMA_KEEP_ALIVE="-1" ollama run flint-local 

Пояснение флагов под ваше железо: 

* OLLAMA_KEEP_ALIVE="-1" — Принудительно держит модель в памяти горячей. Она не выгрузится через 5 минут простоя, и агент будет отвечать мгновенно при каждом вызове.
* --num_gpu 20 (встроено в модель) — Загружает ровно 20 слоев в 11 ГБ VRAM вашей GTX 1080 Ti, исключая ошибки нехватки памяти.
* --num_thread 14 (встроено в модель) — Задействует только 14 физических ядер процессора Xeon, отключая неэффективный для LLM гипертрединг.

Как только в терминале появится строка ввода >>>, модель успешно загружена. Из этого окна чата можно выйти, нажав комбинацию клавиш Ctrl + D — благодаря флагу KEEP_ALIVE модель останется активной в фоне. 

1. ПРОВЕРКА СТАТУСА ВИДЕОКАРТЫ (CUDA)

Чтобы лично убедиться, что ваша MSI GTX 1080 Ti задействована в вычислениях, откройте соседнюю вкладку терминала (пока модель запущена) и введите: 

nvidia-smi 

В нижней секции "Processes" должна отображаться строка "ollama" или "llama-server", а в графе "Memory-Usage" должно быть занято около 6–8 ГБ видеопамяти. 

1. РАБОТА С АГЕНТОМ OPENCODE

Теперь ваша локальная модель полностью готова принимать запросы от CLI-агента. Перейдите в каталог вашего проекта (например, SkladNew) и запускайте агента, указав имя вашей оптимизированной локальной сборки: 

opencode --model flint-local 

Памятка по именам: 

* Полное исходное имя из кэша: hf.co/unsloth/flint-GGUF:UD-Q4_K_XL
* Ваше новое оптимизированное имя для работы: flint-local
